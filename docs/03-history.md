## B2B 발주 시스템 (PR #27~#49)

### Phase 1 — 권한과 회원

- **#27 (1-A) 관리자 권한 분리.** 거래처도 `authenticated` 가 되므로 "로그인 = 관리자"
  가정이 깨진다. `admins` 테이블 + `is_admin()` 기준으로 **전 테이블 RLS 를 교체**했다.
  이후 모든 작업의 선행 조건.
- **#28 (1-B) 거래처 가입·승인.** `partners`, `/order` 영역, 국세청 검증, `partner-docs`
  private 버킷, 관리자 거래처 탭. 보호 컬럼(할인율·상태·메모)은 RLS 로 컬럼 제어가 안 돼
  `partners_guard` 트리거로 막는다.

### Phase 2 — 가격과 발주

- **#29 (2-A) 가격·설정.** `wines` 는 공개 read 라 RLS 로 가격 컬럼만 숨길 수 없다 →
  **`wine_prices` 별도 테이블**로 분리하고 승인 거래처·관리자만 읽게 했다.
  `order_settings` key-value 도입.
- **#30 (2-B) 발주.** `cart_items`·`orders`·`order_items`, `submit_order` RPC(서버 계산),
  발주·장바구니·발주 내역 화면, 관리자 발주 탭.
- 국세청 스웨거 대조 결과 **휴업·폐업자도 `b_stt` 에 값이 있어** 정상으로 표시되던 버그 발견
  → `b_stt_cd === '01'` 판정으로 수정. 이어서 조회를 버튼 클릭에서 자동 조회로 변경.

### Phase 3 — 알림

- **#31** Supabase Webhook → `/api/notify`. 처음엔 Resend.
- 관리자 메일이 안 온다는 제보 → `net._http_response` 조회로 `{"sent":0,"failed":1}` 확인.
  원인은 **Resend 테스트 모드**(도메인 미인증 시 계정 소유자에게만 발송).
- **#39** Gmail SMTP 로 전환, **#40** 거래처 메일에 관리자 CC 추가.

### Phase 4 — 세금계산서·명세표·부가세

- **#35** 홈택스 반자동 — 대장 CSV + `invoiced_at`.
- **#36** 거래명세표 인쇄/PDF (`src/utils/statement.ts`, 새 창 + `window.print`).
- **#37** **부가세 별도 전환** — `orders.vat_amount` 추가, `submit_order` 재작성,
  명세표·대장·화면 전부 반영.

### 가입 흐름 버그 수정

- **#32** 가입 2단계에서 이메일 변경·되돌아가기.
- **#33** **hydration 오류 수정.** `/order` 를 프리렌더에서 빼고 rewrite 로 홈 HTML 을
  서빙한 것이 React #418/#423 + manifest 404 의 원인이었다 → `/order` 프리렌더 포함,
  rewrite 제거, sitemap 제외. 함께 `pattern='[\d-]{10,12}'` → `'[0-9\-]{10,12}'`
  (Chrome v-flag 에서 `\d` 가 무효).
- **#34** 약관 전체 동의 체크.

### 운영 실무 반영

- **#38** 관리자 **대리 발주** + 수기 거래처(`partners.user_id` nullable) + 품목 단가 수정.
  회원가입 없이도 공급받는자 정보만으로 거래처·발주 관리가 되게 했다.
- **#41** 발주 메모 편집 → 거래명세표 비고란.
- **#42** Order UX 일괄 — 장바구니 저장 신뢰성(순서 보장 체인 + dirty 추적 + 제출 전 재동기화),
  모바일 반응형, 발주 내역·내 정보.
- **#43** 대리 발주·발주 수정에서 `발주 Off`·숨김 와인도 선택 가능.
- **#44** **발주 프로세스 개편** — 입금확인을 상태 흐름에서 분리(`paid_at` 플래그),
  발주 수정 다이얼로그, 발주 복사, 카탈로그 개선.
  ("수입사는 배송 먼저, 입금 나중이 훨씬 많다"는 실무 피드백)
- **#45** 발주 홈 링크 줄과 미입금 배너 겹침 수정.
- **#46** `/order` 공통 탭 내비게이션(발주하기·발주 내역·내 정보) — 파란 링크 나열이던 것을
  탭 UI 로 바꾸고 뒤로가기 동선을 정리.
