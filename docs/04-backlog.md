# 04. 남은 작업

기준일: 2026-08-19 (main `b635db2`, PR #49 머지 완료). 열린 PR 없음.

## A. 운영자(사용자)가 직접 해야 하는 설정 — **미완**

이걸 안 하면 기능이 있어도 동작하지 않습니다.

1. **Gmail 앱 비밀번호** — 구글 계정 2단계 인증 → 앱 비밀번호 발급 →
   Vercel 환경변수 `GMAIL_USER`, `GMAIL_APP_PASSWORD` 등록 → **Redeploy** → 테스트 발송 확인.
   (미설정이면 가입·승인·발주 알림 메일이 나가지 않는다.)
2. **와인별 공급가 + 발주 가능 토글 + 재고 입력** — 관리자 `와인 관리` 탭.
   공급가가 없거나 `발주 가능` 이 꺼져 있으면 거래처 발주 화면이 빈 목록으로 보인다.
   재고는 비워두면 "재고 관리 안 함"(무제한)이다.
3. **약관 문안 확정** — `OrderTermsPage` / `OrderPrivacyPage` 의 `[ ]` 자리
   (시행일, 개인정보 보호책임자).
4. **Resend API 키 폐기·재발급** — 과거 대화에 키가 노출된 적이 있다. 현재 발송 경로는
   Gmail 이라 기능 영향은 없지만 정리 필요.

## B. 보류로 결정된 항목

| 항목 | 재개 조건 |
| --- | --- |
| 카카오 알림톡 (2단계 알림) | 카카오 채널 개설 + 솔라피 등 발송사 가입이 선행 |
| 휴대폰 본인인증(성인 확인) | 사업자 승인으로 갈음 중. 규제·실무 요구가 생기면 착수 |

## C. 불필요로 결정된 항목

택배 송장 입력(직접 배송), 거래처 누적 발주 표시, 팝빌 전자세금계산서 연동.

## D. 기술 백로그 (우선순위 순)

1. **Dependabot 취약점 44건** 점검 — 다수가 개발 의존성일 가능성이 크지만 확인 필요.
2. **수기 거래처 ↔ 계정 병합** — 관리자가 만든 `user_id = null` 거래처를, 같은 사업자가
   나중에 회원가입했을 때 잇는 절차가 없다.
3. **관리자 리팩터링(중간 우선순위)**
   - 탭마다 중복된 검색·필터·버튼 툴바를 공용 컴포넌트로 추출
   - 리스트 로드/새로고침 로직을 공용 훅으로 추출
   - 발주 행 액션 버튼이 많아졌으니 Dropdown 으로 축약
   - 와인 탭 스위치 4개(노출·솔드아웃·발주가능·추천) 정리
   - 오늘 출고 품목 집계 뷰
4. **발주 내역 페이지네이션** — 현재 전량 로드.
5. **배송지 여러 개 저장**, **희망 배송일 입력**.
6. **루트 README** 는 이번에 교체했지만, 신규 참여자용 로컬 셋업 절차(Supabase 프로젝트
   생성 → 마이그레이션 순서 실행)는 아직 실측 검증 전.

## E. 손대기 전에 알아야 할 함정

- `/order` 를 프리렌더에서 제외하지 말 것 (React #418/#423 재발).
- 할인·부가세 규칙은 `submit_order` RPC 와 `src/api/pricing.ts` 두 곳을 함께 고칠 것.
- 마이그레이션은 CLI 가 아니라 Supabase Dashboard SQL Editor 에 사람이 실행한다.
  새 SQL 을 만들면 "쿼리 보여줘" 요청에 맞춰 전문을 제시해야 한다.
- 머지는 사용자가 수행한다 (`gh pr merge` 는 이 환경에서 차단됨).
